#Deflector

Is a 2d game where you have to protect the ship you ride from asteroids using the shield on the ship.

**Mouse Cursor**: Used to control the shield around the ship.
**Left-Click**: Unleashes a emp blast to reflect all the incoming asteroids (5 sec cooldown).
**Spacebar**: To start / restart the game.
**Keys [1] & [2]**: Select your system upgrade at score milestones:
  - `[1]`: Increase shield arc (+0.3 radians).
  - `[2]`: Ship repair (+1 Ship HP).
